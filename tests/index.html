DOCUMENT AUTOFILL — BROWSER TESTS

The half of the suite that needs a real browser: image preprocessing, PDF.js, OCR, IndexedDB, live network behaviour and web-link retrieval. Run node tests/run-node.js for the rest.
Serve this over http rather than opening the file directly, so IndexedDB and PDF.js workers behave normally:
python -m http.server 8000 then open http://localhost:8000/tests/
The OCR tests download the recognition engine on first run and take up to a minute.
